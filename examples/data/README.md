# Synthetic modeling data

`observations.csv` contains 60 monthly observations per synthetic location, from 2020-01 to 2024-12. `boundaries.geojson` contains two invented rectangles. They are test fixtures, not measurements or administrative boundaries.

In the reference app, choose Datasets → New dataset, upload both files, then select an available compatible model on the evaluation form. The built-in Persistence model is a quick smoke-test choice when enabled on the Chap server.
