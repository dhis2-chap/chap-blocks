# @chap-blocks/ui

Presentational blocks for charts, maps, tables, forms, layout and search. Use subpath imports such as `@chap-blocks/ui/search` or `@chap-blocks/ui/charts`. Components receive data and callbacks; they do not create a Chap connection. Maps use dataset boundaries by default, with an optional host-supplied basemap.

See [reuse instructions](../../docs/reuse.md) and [architecture](../../docs/architecture.md). Packages expose TypeScript source and are not published to npm. Preserve [upstream notices](UPSTREAM.md) when extracting source.
