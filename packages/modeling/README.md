# @chap-blocks/modeling

Composed modeling screens for datasets, evaluations, predictions, models, jobs and alerts. Import feature subpaths or mount `ModelingApp` inside `ChapProvider`. Full screens follow the reference data-router contract. Standalone entry forms use uploaded or saved Chap datasets; DHIS2 data exchange is optional.

See [reuse instructions](../../docs/reuse.md) and [architecture](../../docs/architecture.md). Packages expose TypeScript source and are not published to npm. Preserve [upstream notices](UPSTREAM.md) when extracting source.
