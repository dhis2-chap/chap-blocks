# Settings

**General** configures the Chap API URL, an optional bearer token, and an optional DHIS2 data-source URL. URLs are stored in this browser. Tokens are held only in session storage and are cleared when the browser session ends.

**Modeling defaults** edits settings on the Chap server, shared by every user of that server: baseline models, metrics and backtest parameters.

**Experimental** stores local feature preferences separately for each Chap server.

**Data pruning** is a DHIS2 maintenance operation and is available only when a DHIS2 source is connected. It does not prune Chap datasets.
