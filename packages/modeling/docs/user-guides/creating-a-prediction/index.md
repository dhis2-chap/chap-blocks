# Creating a prediction

Open a completed evaluation and choose **Create prediction setup**. Name the setup and save it. It retains the configured model and evaluation context.

Open **Predict**, select your setup and choose **Run prediction → Saved dataset**. Select an updated dataset with the same period type and all the setup locations, enter a run name and a positive forecast horizon, then submit.

Follow the job in **Jobs**. Open the completed run to inspect uncertainty charts, maps and alerts. Alert policies can be created separately and attached to prediction setups.

A connected DHIS2 instance enables the alternative DHIS2 data-source form and prediction import/export. DHIS2 writes require suitable permissions on that instance.
