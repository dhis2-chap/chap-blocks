# Getting started

1. Open **Settings** and enter your Chap API URL. For local development the default `/chap-api` forwards to `http://localhost:8000`.
2. If your Chap server uses token authentication, enter the bearer token. It is kept only for this browser session.
3. Open **Datasets → New dataset** to upload a CSV and GeoJSON file, or choose an existing dataset.
4. Create an evaluation, inspect its results, then create a prediction setup and run a prediction.

DHIS2 is optional. Connect a DHIS2 server in Settings only if you want to import its analytics, browse organisation units, or write predictions back to DHIS2.
