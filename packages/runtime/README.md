# @chap-blocks/runtime

React integration for a Chap connection: `ChapProvider`, `useChapClient`, query cache, notifications and browser-local preferences. Optional DHIS2 requests have a separate data source. Each provider owns its own client and cache.

See [reuse instructions](../../docs/reuse.md) and [architecture](../../docs/architecture.md). Packages expose TypeScript source and are not published to npm. Preserve [upstream notices](UPSTREAM.md) when extracting source.
